# 차곡 (Chagok)

> 차가 스스로 쌓는 운행 기록.
> 운전 중엔 아무것도 하지 않고, 모든 운행을 경로와 함께 남겨 지난 운전을 지도로 자세히 다시 보게 하고,
> 정비사·중고차 구매자·세무 담당자에게 내밀 보고서로 만들어 주는 Pleos Connect 앱입니다.
> 점수를 매기는 분석 서비스가 아니라, "언제·어디서·몇 km/h로"를 남기는 기록·증빙 앱입니다.

현대자동차그룹 차량용 앱 개발 공모전 출품작입니다.

- 저장소: https://github.com/Dkgkgk622/Chagok
- 휴대폰 보고서 페이지: https://dkgkgk622.github.io/Chagok/report.html (QR로 열면 보고서가 보입니다)

---

## 한눈에 보기

| 언제 | 차곡이 하는 일 |
|---|---|
| **주행 중** (기어 ≠ P) | 화면을 쓰지 않습니다. 백그라운드에서 차량 신호로 운행을 자동 기록합니다. |
| **주차 중** (기어 = P) | 운행 기록, 운행 목적 선택, 상세 보기(경로 지도), 보고서와 QR을 보여줍니다. |
| **차 밖** (휴대폰) | QR을 찍으면 보고서가 휴대폰 브라우저에서 열립니다. 앱 설치나 서버가 필요 없습니다. |

- 설치 후 **한 번만 열면**, 그 뒤로는 재부팅해도 앱을 열지 않고 자동으로 기록합니다.
- 기록은 **차량 안에만** 저장됩니다. 보고서는 QR 주소의 `#` 뒷부분에만 담겨서 웹 서버로 전송되지 않습니다. 단, 지도(차 화면·휴대폰)의 바탕은 OpenStreetMap이라 화면에 보이는 지역의 지도 조각을 OpenStreetMap 서버에서 받아옵니다(경로·기록 자체는 보내지 않음).

## 기능

### 1. 자동 기록
| 기록 | 기준·출처 |
|---|---|
| 운행 시작·종료 (기어 P ↔ D/R/N) | 움직이지 않고 서 있기만 한 운행은 남기지 않음 |
| 주행거리 (출처 4개 + 우선순위) | 계기판 → 차량 트립 미터 → 위치 기반 → 차속×시간. 출처끼리 10% 넘게 다르면 표시하고, 물리적으로 불가능한 계기판 변화는 제외 |
| 급가속·급출발 / 급감속·급정지 | 한국교통안전공단 위험운전행동 기준 (초당 11 km/h 가속, 초당 7.5 km/h 감속). 이어진 동작 하나는 1건으로 집계하고 최고 가속도·지속 시간을 함께 저장 |
| 과속 | 내비게이션 제한속도 + 20 km/h. 구간마다 1건, 과속 시작 시각·지속 시간·최고 속도와 그때의 제한속도, 최고 속도가 난 지점의 위치를 저장 |
| 정지 횟수, 정차 대기 시간, 1분 이상 정차 지점 | 차속 기준 |
| 경로 | 내비게이션 위치, 주행 중 약 15초마다 (속도·제한속도 포함) |
| 정비 신호 | 브레이크액 부족, 워셔액 부족, 전원 차단 경고, 에어백 전개 (상태가 바뀔 때만) |
| 경고등 | 고장·정비 관련 계기판 경고등 24종의 켜짐·꺼짐 시각과 주행거리. 10초 넘게 켜진 것만 기록(시동 때 몇 초간 모든 경고등이 켜지는 점검 제외). 방향지시등·전조등 같은 상태 표시등은 제외, ESC 작동 중 깜빡임은 고장으로 보지 않음 |
| 정비 맡김·찾음 | 그 시점의 주행거리·배터리·켜진 경고등, 정비 중 주행, 찾은 뒤 경고가 "다시 발생"인지 "처음 발생"인지 구분 |
| 기록 공백 추정 | 앱이 꺼져 있던 동안 계기판이 늘었으면 "기록되지 않은 운행(추정)"으로 앱에만 표시하고, 보고서에는 넣지 않음 |

### 2. 주차 중 화면
- **운행 기록:** 운행마다 요약, 운행 목적(업무·출퇴근·개인), 상세 보기, 보고서 버튼이 있습니다. 과속이 있는 운행에는 보라색 점이 붙습니다.
- **상세 보기:** 경로 지도입니다. 긴 경로는 처음 부분부터 1분 점이 화면에 6~7개 보이는 크기로 열리고, 끌기·두 손가락 확대와 "전체 보기"로 나머지를 봅니다(휴대폰 페이지도 같은 규칙).
  - 1분마다 흰 점을 찍습니다. 과속은 항상 표시하고, 급가속·급감속·1분 이상 정차는 켜야 보입니다.
  - 1분 점이나 급가속·급감속·정차 표시를 누르면 시각·속도·제한속도가 나옵니다. 점 사이의 길은 측정값이 없어 누를 수 없습니다.
  - 바탕 지도는 OpenStreetMap(osmdroid, 회색 처리)이고, 인터넷이 없으면 바탕 없이 경로만 그립니다. 두 경우 첫 화면·누를 수 있는 점·+/- 버튼 규칙은 같습니다.
- **업무 운행:** 방문 목적을 입력하는 페이지가 따로 있습니다. 자주 쓰는 목적은 버튼 한 번으로 고를 수 있습니다.
- **알림:** 목적을 정하지 않은 운행이나 방문 목적을 안 적은 업무 운행이 있으면 홈에 알려 줍니다.

### 3. 보고서 (같은 데이터, 다른 독자)
| 보고서 | 독자 | 내용 |
|---|---|---|
보고서 탭은 남에게 내미는 증빙부터 이 순서로 보여 줍니다.

| 보고서 | 독자 | 내용 |
|---|---|---|
| 운행기록부 (업무용 차량) | 세무·회계 | 국세청고시 제2025-8호 별지 서식 ③~⑬ 항목, 사업연도 단위 |
| 정비용 (차량 기록) | 정비사 | 현재 상태(켜진 경고등 포함), 최근 30일 운행 조건, 지금까지의 경고 기록 전체(켜진 시각·주행거리·켜져 있던 시간), 직전 정비 전후 비교 |
| 차 이력 | 중고차 구매자 | 기록 기간, 운행 방식, 에어백·경고·정비 이력 |
| 주간 요약 | 차주 | 주행거리, 운전 습관, 과속 기록, 목적별 거리 |
| 운행 보고서 (운행 1건, 운행 기록에서 엶) | 차주 | 운행 정보, 입력 이력, 휴대폰 지도(OpenStreetMap 바탕). 다른 사람에게 보여 줄 때는 출발·도착 지점 반경 300m를 가릴 수 있음 |

**운행기록부의 원칙**
- 거리는 **계기판 값만** 씁니다. 믿을 수 있게 확인한 값만 칸에 적고, 나머지는 빈칸 + "직접 기재"로 둡니다(빈칸 행은 합계에서 빼고 그렇다고 표시).
- 모든 거리는 계기판 값 그대로 **0.1km 단위로 계산**합니다. 그래서 모든 행에서 ⑤ 주행 전 + ⑦ 주행거리 = ⑥ 주행 후이고, ⑦ 열을 더하면 ⑪ 합계와 정확히 같습니다(따로 반올림해서 0.1km 어긋나는 일이 없음).
- 앞 운행이 끝난 계기판 값과 다음 출발 값이 다르면(기록되지 않은 운행) ⑩비고에 차이를 표시합니다.
- 시동 직후 계기판 값이 늦게 오면, 늘어난 만큼이 이번 운행 거리로 설명될 때만 앞 운행 끝 값을 출발 값으로 씁니다. 설명이 안 되면 ⑤를 비워 둡니다.
- 운행별로 사용자(④)를 바꿀 수 있습니다.
- **목적·방문 목적·사용자처럼 사람이 입력한 값은 입력 시각을 함께 기록합니다.** 운행 하루 이상 뒤에 입력했거나 고친 경우 ⑩비고에 표시합니다. 차량이 자동 기록한 부분과 사람이 입력한 부분을 구분해서 기록의 신빙성을 높이기 위한 장치입니다.
- 위치 정보는 나 자신용 보고서(운행 보고서)에만 들어가고, 정비용·차 이력·운행기록부에는 넣지 않습니다.
- 운행 보고서 QR은 기본으로 전체 경로를 담습니다(본인 휴대폰용). 다른 사람에게 보여 줄 때 **출발·도착 주변 가리기**를 켜면, 출발·도착 지점 반경 300m 안의 점과 표시가 휴대폰 지도에서 빠져 집·회사가 드러나지 않습니다. 차 화면 지도에는 항상 전체가 보입니다.

## 사용한 SDK·API
| 데이터 | 출처 |
|---|---|
| 누적 주행거리, 트립 미터, 배터리, 브레이크, 조향각 | Pleos **Vehicle SDK** 2.3.2 |
| 브레이크액, 워셔액, 전원 차단 경고, 에어백 | Pleos **Vehicle SDK** (Safety) |
| 경고등 | Pleos **Vehicle SDK** (Safety Telltales, `PRIVATE_CAR_SAFETY` 권한) |
| 제한속도, 위치 | Pleos **NaviHelper SDK** 3.0.5 |
| 차속, 기어 | Android Automotive Car API (`PERF_VEHICLE_SPEED`, `GEAR_SELECTION`, `CURRENT_GEAR`) |

모든 값은 변경 알림(리스너)으로만 받고, 주기적으로 조회(폴링)하지 않습니다.

## Pleos 플랫폼 가이드 반영
- **실행 조건:** 기록은 기어가 P가 아닐 때만 합니다. 화면 갱신은 앱이 보일 때만 합니다.
- **백그라운드:** Android 12부터 백그라운드 앱은 운행 시작 순간에 서비스를 새로 켤 수 없습니다. 그래서 허용되는 시점(부팅, 앱 업데이트, 앱 열림)에 기록 서비스를 켜 두고, 차량 신호 변경만 기다립니다.
- **상태 복원:** 진행 중인 운행을 이벤트마다 저장합니다. 앱이 재시작되면 같은 운행으로 이어서 기록합니다.
- **오프라인:** 기록과 보고서·QR은 인터넷 없이 동작합니다. 지도는 인터넷이 없으면 바탕 지도 없이 경로만 그립니다.
- **글자 크기:** 일반 글자 3mm, 경고 4mm 이상(표준 밀도 기준 계산)
- **주행 안전:** 주행 중에는 시스템이 앱 화면을 막고, 차곡도 조작할 요소를 두지 않습니다.

## 실행 방법
1. Android Studio에서 이 폴더를 열고 Gradle 동기화를 합니다.
2. Pleos Connect Emulator v2.1.0(API 34, **Cold Boot**)을 켜고 ▶ Run을 누릅니다.
3. 처음 실행할 때 차속 권한을 허용합니다.
4. Virtual Console에 연결합니다: `adb forward tcp:8088 tcp:8088` → http://127.0.0.1:8088
5. 기어 D → ACCEL(길게) → BRAKE(길게) → P 순서로 조작하면 운행 기록이 생깁니다.
6. (debug 빌드) **데이터 확인 → 시연용 운행 1건 만들기**를 누르면 판교 일대 가상 운행으로 지도와 보고서를 바로 볼 수 있습니다. "시연용"으로 표시됩니다.

배포용(release) 빌드는 R8 코드 축소와 리소스 축소, 한국어·영어 리소스만 넣도록 설정해 두었습니다.

### 휴대폰 보고서 페이지
1. `docs/report.html`을 GitHub Pages로 공개합니다 (Settings → Pages → `/docs`).
2. 앱의 QR 주소(`ChagokApp.REPORT_BASE_URL`)는 https://dkgkgk622.github.io/Chagok/report.html 입니다. 저장소를 다른 이름이나 계정으로 옮기면 이 값을 바꾸고 다시 빌드합니다.
3. 휴대폰 지도는 키 없이 OpenStreetMap 바탕 지도(회색 처리)를 씁니다. 인터넷이나 지도 라이브러리를 못 받으면 단순 그림으로 대신 그립니다.

## 검증 방법 (`verify/`)
에뮬레이터만으로는 확인하기 어려운 판정 로직을 3단계로 검증했습니다. 앱 빌드에는 포함되지 않습니다.

| 단계 | 내용 | 결과 |
|---|---|---|
| L0 정적 점검 | `json_symmetry.py`: 저장하는 JSON 키와 읽는 키가 짝이 맞는지 | 일치 |
| L1 실제 컴파일 | 실제 SDK·라이브러리 jar로 컴파일 | 오류 0 |
| L2 시나리오 | `BehaviorProof.kt`: 가상 주행(에뮬레이터 실측 로그 재현 포함)으로 운행·급가감속·과속·거리·경로·공백·운행기록부·입력 이력·출발/도착 가리기·경고등·지도 첫 화면·바탕 지도 범위·운행 중 시계·시간대 변경 등 확인 | 223/223 통과 |
| L2 경로 왕복 | `RouteCodecProof.kt` + `route_roundtrip.py`: 앱이 압축한 1시간 경로를 휴대폰 페이지의 해독 코드가 복원했을 때 시각 0.5초·위치 약 1m 이내인지 (Chromium) | 일치 |

에뮬레이터 실측으로 찾은 버그(급출발 판정, 0.0km 표시, 정비 중 주행 0km, release 빌드 충돌 등)는 테스트로 옮겨 두었습니다.

## 알려진 한계
- **과속(제한속도):** 에뮬레이터 내비가 제한속도를 보내지 않아 **실차 검증이 필요**합니다.
- **정비 신호 4종·트립 미터:** 에뮬레이터 미지원. **실차 검증이 필요**합니다.
- **경고등(Telltales):** `PRIVATE_CAR_SAFETY` 권한이 필요합니다. 주최 측 안내로 개발 중에는 사용할 수 있지만, 앱마켓 배포 때 권한 승인은 별도 심사입니다. 권한이 없는 환경에서는 데이터 확인 탭에 "미지원"으로 표시되고 나머지 기능은 그대로 동작합니다.
- **타이어 공기압 수치:** 공개 API가 경고 기준값만 주어 사용하지 않습니다(공기압 경고등은 기록합니다).
- **위치:** 내비게이션에서만 받습니다(위치 SDK 준비 중). 점 사이는 직선으로 이어 그립니다.
- **에뮬레이터 계기판:** 주행해도 늘지 않아(콘솔에서 직접 입력) 운행기록부 거리가 비어 보입니다. 실차에서는 계기판 값으로 채워집니다.
- **운행기록부:** 국세청 서식 항목을 따르지만 세무상 인정 여부를 보장하지 않습니다. 신고 전에 세무 전문가와 확인하세요.
- **보고서 번호:** 차 화면과 휴대폰의 내용이 같은지 맞춰 보는 용도이며, 위조를 막지는 못합니다.
- **휴대폰 전달:** 차 화면에서 읽히도록 QR을 약 1,800자 이하로 맞춥니다. 운행기록부는 압축 형식으로 최근 약 35~45건(방문 목적이 없으면 약 85건), 경고 기록 등 긴 목록은 최신 30건까지 담고, 나머지는 차 화면에서 봅니다. 전체 기간 전달은 휴대폰 동반 앱으로 확장할 계획입니다.
